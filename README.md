# Computer Vision Made Easy: code

Runnable Python and OpenCV code for the lessons at **[computervisionmadeeasy.com](https://computervisionmadeeasy.com)**, an interactive course that teaches computer vision from first principles.

Each folder matches one lesson. The lesson explains the idea; the code here lets you run it on your own images.

| # | Lesson | Code |
|---|---|---|
| 1 | [An image is just a grid of numbers](https://computervisionmadeeasy.com/lessons/what-is-a-pixel/) | [01-what-is-a-pixel](01-what-is-a-pixel/) |

More folders are added as lessons are published.

## Setup

Python 3.10 or newer.

```bash
python -m venv .venv
# Windows: .venv\Scripts\activate    macOS/Linux: source .venv/bin/activate
pip install -r requirements.txt
```

Versions are pinned to the ones the examples were tested with.
